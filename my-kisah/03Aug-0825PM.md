# Kisah PMW - 3 Agustus 2026

## Opsi Deadline "Hari Sesi" (Checkbox) untuk Dosen & Mentor

### Apa yang diimplementasikan?
1. **Migrasi Database**: Menambahkan kolom `deadline_mode` (ENUM `days`/`session_date`, default `days`) dan `deadline_time` (TIME, nullable) pada tabel `pmw_guidance_schedules`.
2. **Form Dosen & Mentor**: Menambahkan checkbox **"Deadline pengisian = tanggal sesi"** pada modal "Buat Jadwal". Jika dicentang → input jumlah hari (`deadline_days`) disembunyikan/disabled dan muncul input jam batas (`deadline_time`, default 23:59). Jika tidak dicentang → perilaku lama (X hari setelah sesi).
3. **Service Logic** (`PmwGuidanceService::submitLogbook`): Validasi deadline sekarang mengikuti mode — `session_date` → batas = tanggal sesi + jam custom; `days` → batas = tanggal sesi + X hari (tidak berubah).
4. **Tampilan Mahasiswa**: Deadline kini menampilkan **tanggal sesi + tanggal deadline** sekaligus, misal `Deadline: 08 Agu 2026 (5 hari setelah sesi 03 Agu 2026)` atau `Deadline: 03 Agu 2026, 23:59 (hari sesi)`. Berlaku untuk badge Locked, badge Belum Diisi, dan modal "Akses Pengiriman Terkunci".
5. **Monitoring Admin**: Kolom `deadline_info` di ringkasan tim kini menghitung deadline sesuai mode.

### Mengapa ini dilakukan?
Agar Dosen Pendamping dan Mentor Praktisi fleksibel memilih batas waktu pengisian logbook per-sesi: bisa memberi tenggat beberapa hari setelah sesi, atau mewajibkan mahasiswa mengisi di hari sesi itu juga (dengan jam batas yang bisa diatur).
