# Role Penilai — Perencanaan

## Ringkasan
Merencanakan implementasi role baru "Penilai" untuk verifikasi Pitching Desk.

## Jawaban atas pertanyaan user
- **"kalo penilai kita salin folder dari admin ya?"** → Ya. Controller Penilai = copy dari Admin (beda view path + route guard). Models/DB tetap shared.
- **"lebih jelas lagi plannya"** → Plan sudah di-detilkan per file, ada tabel perbandingan Admin vs Penilai di tiap aspek.

## Keputusan
- Kolom `admin_status`/`admin_catatan` → `status`/`catatan` (generik)
- Kolom baru: `persentase_nilai DECIMAL(5,2)`
- Table `pmw_penilai` baru (pattern = `pmw_reviewers`)
- Views di-copy ke `penilai/pitching/`
- Permission baru: `data.pitching_verify`
- Halaman pitching desk: split by kategori (Pemula/Berkembang)
- Default filter: status=pending, sorting: pending first → persentase_nilai DESC

## Files affected
13 files total:
- 2 migrations (rename kolom + add persentase, create pmw_penilai)
- AuthGroups (group + permission + matrix)
- 2 models (PmwSelectionPitchingModel, PmwProposalModel)
- 2 controllers (Admin/PitchingDeskController edit, Penilai/PitchingDeskController baru)
- 4 views (2 admin edit, 2 penilai copy)
- Routes (grup penilai)
- AdminController (create user)
