**Tanggal:** 23 Oktober 2026  
**Waktu:** ~07:45 WIB  
**Scope:** Mahasiswa — Laporan Milestone

---

## Perubahan

**Sebelumnya:** Laporan Akhir bisa dikumpulkan tanpa bukti dokumentasi boothcamp, dan tidak ada tempat menyimpan berkas dokumentasi tersebut.

**Sesudah:**
- Tab **Laporan Akhir** punya kartu **Dokumentasi Boothcamp** dengan badge Sudah/Belum, tombol Lihat (preview PDF), serta form unggah/ganti.
- PDF divalidasi (ekstensi + MIME `application/pdf`, maks 5MB), disimpan di `writable/uploads/pmw/boothcamp/{proposalId}/`.
- Dokumentasi boleh diunggah/diganti kapan pun, termasuk saat Laporan Akhir sudah `approved`.
- Submit Laporan Akhir ditolak jika dokumentasi belum ada: *"Unggah Dokumentasi Boothcamp terlebih dahulu sebelum mengumpulkan Laporan Akhir."*
- Dokumen disimpan di `pmw_documents` (`type = laporan_akhir`, `doc_key = boothcamp_documentation`) — tanpa migration baru.
- `proposal_id` diambil dari sesi, guard sama dengan submit milestone (record implementasi + periode aktif).
- File lama dihapus setelah update sukses; file baru di-unlink jika transaksi gagal.
