# fix: Preview Dokumentasi Boothcamp 404 di Dosen & Admin

**Tanggal:** 23 Oktober 2026  
**Waktu:** ~09:46 WIB  
**Scope:** Dosen, Admin — Dokumentasi Boothcamp

---

## Masalah

Tombol pratinjau dokumentasi boothcamp mengarah ke `milestone/view/{id}`. Route tersebut memuat data dari `pmw_reports` berdasarkan ID, sedangkan dokumentasi boothcamp tersimpan di `pmw_documents`. Akibatnya data tidak ditemukan dan muncul 404.

## Perbaikan

- Tambah route `milestone/doc/{id}` di group `admin` dan `dosen`.
- Tambah `Admin\MilestoneReportController::viewDocument()` yang:
  - memuat dokumen dari `pmw_documents`,
  - hanya mengizinkan `doc_key = boothcamp_documentation`,
  - memakai guard `canViewReport()` (admin bebas, dosen hanya tim bimbingannya),
  - mengembalikan PDF dengan path `WRITEPATH . file_path` (nilai `file_path` sudah diawali `uploads/`, jadi tidak boleh ditambah `uploads/` lagi).
- Update tombol pratinjau di view dosen & admin ke route baru.
