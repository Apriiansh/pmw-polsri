# fix: Perbaikan Bug Edit & Hapus pada Implementasi List Perjanjian

**Tanggal:** 12 Oktober 2026  
**Waktu:** ~21:50 WIB  
**Scope:** Mahasiswa - Implementasi List Perjanjian (Tahap 7)

---

## Masalah yang Dilaporkan

User melaporkan tombol Edit dan Hapus di menu "Implementasi List Perjanjian" tidak berfungsi (tidak ada aksi/response setelah diklik).

---

## Root Cause Analysis

Ditemukan **3 bug** yang menyebabkan kegagalan ini:

### Bug #1 (UTAMA) — CSRF Token Stale karena `$regenerate = true`

**File:** `app/Config/Security.php`  
**Problem:** `$regenerate = true` menyebabkan CSRF token di-regenerate setelah setiap request POST yang sukses. Namun, semua token di JavaScript (termasuk di `deleteItem`, `deletePhoto`, `deletePayment`, `deleteKonsumsi`, `saveEditItem`, `saveEditPayment`, `saveEditKonsumsi`) di-render saat page load sebagai string literal PHP `<?= csrf_hash() ?>`. Setelah request pertama berhasil (misal `saveItem`), token lama menjadi invalid → semua request DELETE/PUT berikutnya ditolak dengan error 400/419 CSRF failure.

**Fix:** Set `$regenerate = false`. Proteksi CSRF dengan `csrfProtection = 'session'` tetap aktif dan aman tanpa perlu regenerate setiap request.

### Bug #2 — Duplikat Definisi Fungsi Alpine.js

**File:** `app/Views/mahasiswa/implementasi.php`  
**Problem:** Fungsi `openEditItem`, `openEditPayment`, `openEditKonsumsi` masing-masing didefinisikan dua kali dalam Alpine.js component. Definisi pertama (lebih sederhana, tanpa fallback) menimpa definisi kedua (lebih lengkap, dengan default values). Akibatnya modal edit tidak ter-populate dengan benar.

**Fix:** Hapus definisi duplikat pertama, pertahankan versi yang lebih lengkap.

### Bug #3 — HTTP Method Case Mismatch di Controller

**File:** `app/Controllers/Mahasiswa/ImplementasiController.php`  
**Problem:** Guard condition menggunakan `$this->request->getMethod() !== 'delete'` (lowercase), namun CI4 `getMethod()` mengembalikan uppercase (`'DELETE'`). Bisa menyebabkan guard tidak berfungsi sesuai harapan.

**Fix:** Wrap dengan `strtolower()` → `strtolower($this->request->getMethod()) !== 'delete'`.
