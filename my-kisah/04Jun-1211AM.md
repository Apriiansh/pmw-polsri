### Implementasi Alpine.js (unified state)
```js
x-data="{
    nilai: <?= !empty($proposal['pitching_persentase_nilai']) ? (float)$proposal['pitching_persentase_nilai'] : 0 ?>,
    get v() { return parseFloat(this.nilai); },
    get valid() { ... },
    get accent() { return !this.valid ? '#94a3b8' : (this.v >= 80 ? '#10b981' : '#f43f5e'); },
    get label() { /* LOLOS / BELUM LOLOS / — */ },
    get pos() { return this.valid ? Math.min(98, Math.max(2, this.v)) : 0; },
    syncRadio() {
        if (!this.valid) return;
        const target = this.v >= 80 ? 'approved' : 'rejected';
        const radio = this.$root.querySelector(`input[name=status][value='${target}']`);
        if (radio && !radio.checked) radio.checked = true;
    },
    onRadioChange(value) {
        if (value === 'approved') this.nilai = 90;
        else if (value === 'rejected') this.nilai = 40;
    }
}" x-init="syncRadio(); $watch('nilai', () => syncRadio())"
```

### Behavior Sync (two-way)
| Aksi User | Hasil |
|-----------|-------|
| Load halaman dgn existing data | `x-init` panggil `syncRadio()` → radio checked sesuai nilai existing |
| Geser slider | `x-model="nilai"` trigger `$watch` → `syncRadio()` → radio auto-check |
| Klik radio "Lolos" | `@change="onRadioChange('approved')"` → `nilai = 90` → slider visual ke 90 + radio tetap checked |
| Klik radio "Belum Lolos" | `@change="onRadioChange('rejected')"` → `nilai = 40` → slider visual ke 40 |
| Klik Reset | `nilai = 0` → `syncRadio()` set "rejected" (0 < 80) |

### Pitfall Diperbaiki: HTML Attribute Quoting
Awalnya pakai template literal dengan double-quote CSS selector: `` `input[name=status][value="${target}"]` ``
→ BROKEN: `"` di dalam backtick akan terminate HTML attribute `x-data="..."` lebih awal.

Fix: pakai single-quote CSS selector yang valid: `` `input[name=status][value='${target}']` ``
→ CSS attribute selector `[value='x']` valid dan match `value="x"` di HTML.

Verified via PHP DOM parser simulation: 0 unescaped double quotes inside x-data → attribute intact.
