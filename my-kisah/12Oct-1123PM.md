## Perubahan yang Dilakukan

Sebelumnya, fitur upload laporan magang hanya tersedia untuk tim dengan kategori `pemula`. Sekarang, tim dengan kategori `berkembang` juga bisa mengakses dan mengunggah laporan magang.

| File | Perubahan |
|------|-----------|
| `app/Controllers/Mahasiswa/MilestoneReportController.php` | Hapus filter `kategori_wirausaha !== 'pemula'` yang memblokir akses magang untuk berkembang |
| `app/Views/mahasiswa/laporan_pmw.php` | Hapus `<?php if ($proposal['kategori_wirausaha'] === 'pemula'): ?>` dari tab button dan template magang |

| `app/Views/admin/laporan_pmw.php` | Update label subtitle dari "Khusus Tim Pemula" → "Semua Kategori Usaha"; hapus kondisi `N/A` untuk non-pemula di tabel monitoring |

## Perilaku Setelah Perubahan

- **Mahasiswa Berkembang**: Tab "Laporan Magang" muncul di halaman laporan, form upload tersedia jika jadwal admin sudah dibuka.
- **Dosen**: Kolom laporan magang kini ditampilkan untuk semua tim bimbingan (bukan hanya pemula).
- **Admin**: Label jadwal magang diubah; di monitoring, semua tim menampilkan status laporan magang (bukan N/A).
- **Jadwal Admin**: Satu jadwal magang berlaku untuk semua kategori (tidak perlu perubahan DB).
