## Perubahan

**Sebelumnya:** `submit()` mengambil `proposal_id` langsung dari hidden input form tanpa verifikasi kepemilikan, sehingga mahasiswa bisa mengunggah laporan untuk tim lain. Route `milestone/view` dan aksi dosen `verify` juga bisa diakses dengan menebak ID laporan tim lain.

**Sesudah:**
- `proposal_id` selalu diambil dari sesi (`getProposalByUserId`), hidden input dihapus dari view.
- Submit memvalidasi ulang guard yang sama dengan `index()` (record implementasi + periode aktif) dan memastikan `schedule_id` milik periode aktif.
- `viewFile()` membatasi akses: admin bebas, mahasiswa hanya proposal sendiri, dosen hanya tim bimbingannya.
- `verify()` memvalidasi status dan memastikan dosen adalah pembimbing proposal terkait.
- File upload tidak lagi tersimpan sebelum cek `approved`, dan file lama dihapus saat replace.
